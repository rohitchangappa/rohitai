Privacy policy

RohitAI Personal Assistant · last updated 9 November 2026

Who uses it

RohitAI is a private application used only by its owner, Rohit Changappa, with his own Google account. It is not available to anyone else.

What Google data it accesses

With the owner's permission, RohitAI reads messages in the owner's own Gmail account so it can sort them into "needs attention", "for information" and "junk". When the owner chooses, it can move messages he has marked as junk to Gmail Trash. It does not send email.

Where data is kept

Sorting results are stored on the owner's own computer. Sign-in tokens are stored encrypted on that computer. Email text is sent to Anthropic's Claude API only to decide how a message should be sorted; it is not sold, shared with advertisers, or used for any other purpose.

Google API Services User Data Policy

RohitAI's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove RohitAI's access at any time at myaccount.google.com/permissions, and can delete the data stored on his computer.
